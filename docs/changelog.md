# 更新日志

这里记录 Lumo-Hub 的正式版本与测试版更新。版本日期以 GitHub Release 为准。

## 0.0.1-beta.2

**发布日期：2026-10-22 · 测试版**

- ✨️ 新增取色器与色板、剪贴板历史、二维码、文本工具箱、悬浮文本和时间戳六个内置工具，支持快捷启动与关键词搜索。
- ✨️ 色板内置经典颜色、莫兰迪色和中国传统色，支持标签切换、选色、复制与收藏。
- 🐛 修复 Windows 创建工具窗口时的卡死和空白问题，改为异步打开独立工具窗口。
- 🐛 改进测试版更新检查与 Windows 通知反馈，提供可重试的错误提示。
- 🎨 统一设置与工具界面样式，时间戳日期选择采用 shadcn-vue DatePicker，悬浮文本支持置顶与自动保存。

[查看 v0.0.1-beta.2 Release](https://github.com/yeyongzhi/Lumo-Hub/releases/tag/v0.0.1-beta.2)

## 0.0.1-beta.1

**发布日期：2026-10-17 · 测试版**

- **快捷启动**：新增任务管理器和 Windows 设置；支持按回车启动、固定分组与面板快捷操作。
- **应用库与外观**：优化分组、排序和快捷启动面板布局，支持亮色与暗色主题。
- **稳定性**：提升笔记文件异常处理和回收站恢复可靠性，避免异常文件影响已有数据。
- **兼容性**：改进本地设置迁移和系统工具兼容性。

[查看 v0.0.1-beta.1 Release](https://github.com/yeyongzhi/Lumo-Hub/releases/tag/v0.0.1-beta.1)

## 0.0.1-beta.0

**发布日期：2026-10-16 · 首个测试版**

- 发布本地优先的 Windows 桌面效率工作台，包含应用库、快捷启动、笔记、便签、倒数日、备份恢复和系统托盘。
- 提供 Windows x64 NSIS 安装包，支持手动安装。
- Beta 阶段通过 Release 安装包手动更新。

[查看 v0.0.1-beta.0 Release](https://github.com/yeyongzhi/Lumo-Hub/releases/tag/v0.0.1-beta.0)
