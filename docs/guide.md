# 产品功能

Lumo-Hub 是一款面向 Windows 的本地优先桌面效率工作台。你可以用它整理常用工具、集中记录内容，并按自己的习惯布置桌面工作空间。

## 快捷启动

按 **Alt + Space** 唤出快捷启动面板。输入应用、网页或文件名称，也可以输入拼音或别名；用方向键选择结果，按 **Enter** 打开，按 **Esc** 收起。面板支持最近使用、固定项、系统启动项和应用库分组，也可在设置中调整面板尺寸和分区顺序。

## 应用库

应用库可管理应用、网页和文件启动项。你可以创建分组、收藏常用项目、调整排序、扫描本机桌面及微软商店应用并勾选导入，支持拖入应用、快捷方式、文件和文件夹，也可以配置系统启动项（例如文件资源管理器、PowerShell、任务管理器和 Windows 设置）。

## 内置工具

按 **Alt + Space** 打开快捷启动面板，从「内置工具」列表选择，或输入下表中的名称和关键词后按 **Enter**。目前共有 11 个工具。每个工具在独立窗口中打开，可以拖动标题栏移动窗口、拖动窗口边缘放大，也可以用标题栏的图钉切换置顶。

| 工具 | 核心操作 | 搜索示例 |
| --- | --- | --- |
| 取色器 + 色板 | 屏幕取色、HEX/RGB/HSL 转换、经典/莫兰迪/中国传统色板、收藏颜色 | `color picker`、`colorPicker` |
| 剪贴板 | 自动记录文本和图片、搜索、再次复制、删除、暂停记录 | `clipboard`、`复制` |
| 二维码工具 | 输入内容生成二维码并保存 PNG，从图片识别二维码 | `qrcode`、`二维码` |
| 文本工具箱 | 文本清理、排序、大小写转换、URL 与 Base64 编解码 | `text`、`去重` |
| 悬浮文本 | 自动保存文本、默认置顶 | `floating`、`悬浮` |
| 日历 | 月历、农历、节气、节日、调休标记及传统黄历 | `日历`、`calendar` |
| 时间戳工具 | 秒/毫秒时间戳与日期互转，日历选择日期并输入时分秒 | `timestamp`、`时间戳` |
| JSON 工具 | 格式化、压缩、校验语法并定位错误 | `json`、`校验` |
| 文本对比 | 左右按行对照，标记新增、删除和修改 | `diff`、`文本对比` |
| 番茄钟 / 计时器 | 专注、休息、自定义倒计时、正计时和到时提醒 | `pomodoro`、`计时器` |
| 单位换算 | 长度、重量、温度和文件大小互转 | `unit`、`单位换算` |

### 取色器 + 色板

点击「屏幕取色」，再点击屏幕上的目标像素。也可以直接输入 HEX 色值，工具会同步展示 HEX、RGB 和 HSL，并提供复制按钮。下方可查看类似色、互补色和内置色板，点击色块即可载入该颜色。常用颜色可以收藏到本机色板。

屏幕取色依赖 WebView2 的取色接口。也可以手动输入色值来转换和收藏。

### 剪贴板

应用运行期间会记录新复制的文本和图片。用「全部」「文本」「图片」切换类型，或在搜索框按文本内容查找。点击某条记录的「复制」，即可把内容放回系统剪贴板。列表独立滚动，搜索和筛选始终留在上方。

历史保存在本机，最多保留 200 条，序列化后总大小上限为 32 MB。单条文本上限为 1 MB，单张图片的原始像素数据上限为 16 MB。可以暂停记录、删除单条或清空历史，暂停状态会保留。

### 二维码工具

在左侧输入链接或文本，预览会随输入更新。点击「保存 PNG 图片」可选择保存位置。在右侧点击「选择图片」，即可离线识别图片里的二维码并复制结果。识别出的链接以文本显示，由你决定是否打开。

### 文本工具箱

把内容粘贴到输入区，选择逐行去重、去除首尾空白、删除空行、逐行排序或大小写转换。工具也提供 JSON 格式化和压缩，以及 URL、Base64 编解码。需要连续处理时，点击「结果作为输入」，再选择下一项操作。

### 悬浮文本

适合放置临时清单、操作步骤或需要随时看到的文字。输入内容后会自动保存到本机，下次打开时继续编辑。窗口默认置顶，点击标题栏图钉可切换。正文和其他内置工具一样，跟随「设置 → 外观 → 全局字体大小」。

### 日历

支持查看 1900–2100 年的月历。可选择年月、切换上月或下月，也可点击「今天」返回当前日期。选中日期后可查看农历、节气、节日、生肖、星座、月相和传统黄历。

「休」「班」标记来自内置的中国大陆节假日数据，覆盖范围随数据版本而定。黄历宜忌和方位属于传统民俗信息。

### 时间戳工具

顶部显示可复制的当前 Unix 秒级时间戳。把已有时间戳粘贴到「时间戳 → 日期」，选择「秒」或「毫秒」后转换。反向转换时，在日历中选择日期并填写本地时、分、秒，即可得到对应的时间戳。两个方向的转换结果均可复制。

### JSON 工具

在左侧粘贴 JSON，再选择所需操作。

- **格式化**使用两个空格缩进，适合阅读嵌套对象和数组。
- **压缩**移除结构之间的空白，保留字符串里的空格和转义字符。格式化与压缩都保留原始数字写法，适用于含长整数 ID 的数据。
- **校验**检查 JSON 语法。如果解析器提供了错误位置，工具会显示行列号并把光标移到对应位置。

转换结果显示在右侧，可直接复制。

### 文本对比

把原文粘贴到左侧、修改稿粘贴到右侧，再点击「对比文本」。结果按行对齐并显示两边的行号。绿色 **+** 表示新增，红色 **−** 表示删除，黄色 **~** 表示修改。顶部同时显示各类变更的数量。

每侧最多可比较 2,000 行。编辑任意一侧后，点击「对比文本」重新计算结果。

### 番茄钟 / 计时器

- **番茄钟**提供 25 分钟专注和 5 分钟休息，使用界面上的按钮手动切换。
- **倒计时**可分别设置分钟和秒，适合短时任务。要更改已开始的时长，先点击「重置」。
- **正计时**从零开始累计时间，适合记录一段任务的耗时。

计时可以暂停、继续和重置。番茄钟或倒计时结束时，窗口会显示完成提示，并尝试发送 Windows 系统通知。使用标题栏图钉可将计时窗口保持在前方。计时期间请保持工具窗口打开。

### 单位换算

先选择分类，再选择原单位和目标单位，输入数值即可看到结果。中间的双向箭头可以交换两个单位。

| 分类 | 常用换算示例 |
| --- | --- |
| 长度 | 米、厘米、千米、英寸、英尺和英里 |
| 重量 | 千克、克、吨、磅和盎司 |
| 温度 | 摄氏度、华氏度和开尔文 |
| 文件大小 | 字节、KB、MB、GB、TB，以及 KiB、MiB、GiB、TiB |

文件大小同时支持十进制和二进制单位。1 MB 等于 1,000,000 B，1 MiB 等于 1,048,576 B。

## 首页与日常记录

首页由可配置卡片组成，可加入日期时间、最近打开、便签、笔记、倒数日、天气和每日内容等模块，并选择简洁、工作或生活布局。

- **便签**适合临时记录，可置顶；删除后可从回收站恢复。
- **Markdown 笔记**适合整理较长内容，支持标签、预览和文件异常检查。
- **倒数日**用于记录纪念日、目标日期和重要事项。

## 数据、备份与隐私

工作内容默认保存在本机，不需要注册账号。应用支持导出备份、恢复备份、定期备份、回收站以及迁移数据目录。普通卸载会保留用户数据；若要清除数据，请使用开始菜单中的“卸载并清理数据”。

桌面应用默认数据位置与迁移方式会因安装版本和系统环境而不同。迁移前会自动备份，恢复备份前也会先备份当前数据。仍建议定期将导出的备份保存到另一块磁盘或安全位置。

## 安装与更新

从 [GitHub Releases](https://github.com/yeyongzhi/Lumo-Hub/releases) 下载 Windows x64 安装包并运行。当前版本处于 Beta 阶段；Beta 版本可能存在未发现的问题，请先备份重要资料。Beta 版本可手动安装更新，也可在“设置 → 关于”检查更新；在线更新需要发布源可访问并提供签名安装包与清单。完整步骤见[安装说明](/install)。
