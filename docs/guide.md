# 产品功能

Lumo-Hub 是一款面向 Windows 的本地优先桌面效率工作台。你可以用它整理常用工具、集中记录内容，并按自己的习惯布置桌面工作空间。

## 快捷启动

按 **Alt + Space** 唤出快捷启动面板。输入应用、网页或文件名称，也可以输入拼音或别名；用方向键选择结果，按 **Enter** 打开，按 **Esc** 收起。面板支持最近使用、固定项、系统启动项和应用库分组，也可在设置中调整面板尺寸和分区顺序。

## 应用库

应用库可管理应用、网页和文件启动项。你可以创建分组、收藏常用项目、调整排序、扫描本机桌面及微软商店应用并勾选导入，支持拖入应用、快捷方式、文件和文件夹，也可以配置系统启动项（例如文件资源管理器、PowerShell、任务管理器和 Windows 设置）。

## 内置工具

快捷启动面板展示七个内置工具，也可在主窗口全局搜索中输入名称或关键词后打开。工具窗口可独立移动、置顶和关闭。

| 工具 | 核心操作 | 搜索示例 |
| --- | --- | --- |
| 取色器 + 色板 | 屏幕取色、HEX/RGB/HSL 转换、经典/莫兰迪/中国传统色板、收藏颜色 | `color picker`、`colorPicker` |
| 剪贴板 | 自动记录文本和图片、搜索、再次复制、删除、暂停记录 | `clipboard`、`复制` |
| 二维码 | 输入内容生成二维码并保存 PNG，从图片识别二维码 | `qrcode`、`二维码` |
| 文本工具箱 | 逐行去重、大小写、JSON 格式化、URL 与 Base64 编解码 | `text`、`JSON` |
| 悬浮文本 | 自动保存文本、默认置顶、调整字号 | `floating`、`悬浮` |
| 日历 | 月历、农历、节气、节日、调休标记及传统黄历 | `日历`、`calendar` |
| 时间戳工具 | 秒/毫秒时间戳与日期互转，日历选择日期并输入时分秒 | `timestamp`、`时间戳` |

剪贴板仅记录应用运行期间的新复制内容，保存在本机；历史上限为 200 条 / 32 MB，单条文本上限 1 MB、图片原始像素上限 16 MB。可暂停记录、删除单条或清空历史；暂停状态会保留。屏幕取色需要系统 WebView2 支持取色接口。

## 首页与日常记录

首页由可配置卡片组成，可加入日期时间、最近打开、便签、笔记、倒数日、天气和每日内容等模块，并选择简洁、工作或生活布局。

- **便签**适合临时记录，可置顶；删除后可从回收站恢复。
- **Markdown 笔记**适合整理较长内容，支持标签、预览和文件异常检查。
- **倒数日**用于记录纪念日、目标日期和重要事项。

## 数据、备份与隐私

工作内容默认保存在本机，不需要注册账号。应用支持导出备份、恢复备份、定期备份、回收站以及迁移数据目录。普通卸载会保留用户数据；若要清除数据，请使用开始菜单中的“卸载并清理数据”。

桌面应用默认数据位置与迁移方式会因安装版本和系统环境而不同。迁移前会自动备份，恢复备份前也会先备份当前数据。仍建议定期将导出的备份保存到另一块磁盘或安全位置。

## 安装与更新

从 [GitHub Releases](https://github.com/yeyongzhi/Lumo-Hub/releases/tag/v0.0.1-beta.6) 下载 Windows x64 安装包并运行。当前版本处于 Beta 阶段；Beta 版本可能存在未发现的问题，请先备份重要资料。Beta 版本可手动安装更新，也可在“设置 → 关于”检查更新；在线更新需要发布源可访问并提供签名安装包与清单。完整步骤见[安装说明](/install)。

## 问题反馈

遇到问题时，请在 [GitHub Issues](https://github.com/yeyongzhi/Lumo-Hub/issues) 提交反馈，并说明 Windows 版本、应用版本、复现步骤和预期结果。请勿上传包含个人信息的数据库或备份文件。


### 日历

在快捷启动或全局搜索输入「日历」「农历」即可打开。支持 1900–2100 年的年月选择、上/下月切换、回到今天和日期详情；展示农历、节气、节日、生肖、星座、月相及传统黄历。休/班标记采用 lunar-typescript 内置的中国大陆节假日数据，未收录年份不标注调休。黄历宜忌与方位为传统民俗信息。
