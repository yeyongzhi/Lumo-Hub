# 安装与首次使用

## 系统要求

当前提供 Windows x64 测试版，运行需要 Microsoft Edge WebView2 Runtime。安装程序会按 Tauri 的默认方式检查 WebView2；缺少运行时时可能需要联网下载安装。

## 下载与安装

1. 打开 [v0.0.1-beta.4 测试版发布页面](https://github.com/yeyongzhi/Lumo-Hub/releases/tag/v0.0.1-beta.4)。
2. 下载 `Lumo-Hub_0.0.1-beta.4_x64-setup.exe`，运行并按安装向导选择安装目录。
3. 首次启动完成欢迎页，按 `Alt + Space` 打开快捷启动面板。
4. 搜索应用或内置工具，例如 `color picker`、`clipboard`、`timestamp`，按 Enter 或点击打开。

版本发布与资产可用情况以 Release 页面为准。测试版升级前请在“设置 → 数据与备份”导出重要数据备份。

## 更新与卸载

在“设置 → 关于”检查更新，或从 Release 页面下载安装包更新。Beta 更新通过对应版本的签名清单校验；无法连接发布源时可以重试或手动下载安装。

普通卸载保留用户数据；需要彻底清理时使用开始菜单中的“卸载并清理数据”。安装版数据默认与程序安装目录关联，可在设置中查看实际位置。

继续阅读[功能与使用指南](/guide)或[更新日志](/changelog)。
